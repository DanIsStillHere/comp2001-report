# comp2001-report

Within this repository you will find the source code for my micro-service.

It is a Flask application that uses Connexion to create a REST API that allows for the CRUD operations of users, trails, and their features. These changes are made persistent through the usage of a database that is connected to through using SQLAlchemy and Marshmallow. The relationships between the data tables are defined within the Python code.

All requirements for the app were met with the exception of using the Authenticator API. I attempted to implement its usage however I ran out of time.
